# VLSI-Side-Channel-Attack-Detection-System

## Project Overview

This project focuses on detecting side-channel attacks in FPGA and System-on-Chip (SoC) architectures using hardware-based security mechanisms.

## Technologies Used

- Verilog HDL
- FPGA
- VLSI Design
- ModelSim

## Features

- Clock Attack Detection
- Logic Attack Detection
- Delay Detection
- Side Channel Attack Analysis

## Project Modules

- Attack Generator
- Benchmark Circuit 1
- Benchmark Circuit 2
- Buffer Module
- Clock Synthesizer
- Delay Detector
- Logic Attack Detector
- Reference Signal Generator
- Test Bench Module
